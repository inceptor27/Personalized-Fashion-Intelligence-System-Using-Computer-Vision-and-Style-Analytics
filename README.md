## 📖 Overview

StyleAI is an AI-powered fashion intelligence platform that provides personalised outfit recommendations using **Computer Vision**, **Deep Learning**, and **Style Analytics**.

The system analyses clothing, body shape, and skin tone to recommend outfits tailored to individual users. It also includes Virtual Try-On capabilities and an AI Fashion Stylist to enhance the overall shopping experience.

This project was developed as a Final Year Integrated M.Tech Capstone Project at **Vellore Institute of Technology (VIT), Vellore**.


Install dependencies


